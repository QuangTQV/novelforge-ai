# 多语言 / Đa ngôn ngữ / Internationalization (i18n)

客户端 UI 现在通过 `react-i18next` 支持多语言。翻译文本与代码分离，集中在
`client/src/i18n/locales/<lang>/<namespace>.json`，改语言只改 JSON，不用碰组件。

Giao diện client hỗ trợ đa ngôn ngữ qua `react-i18next`. Văn bản dịch tách khỏi code,
tập trung ở `client/src/i18n/locales/<lang>/<namespace>.json` — sửa ngôn ngữ chỉ cần
sửa JSON, không đụng vào component.

The client UI is multilingual via `react-i18next`. Translation text lives apart from
code in `client/src/i18n/locales/<lang>/<namespace>.json` — editing a language means
editing JSON only, never components.

支持的语言 / Ngôn ngữ hỗ trợ / Supported: **Tiếng Việt (`vi`, mặc định / fallback)**,
简体中文 (`zh`), English (`en`).

## 目录结构 / Cấu trúc thư mục / Layout

```
client/src/i18n/
├── config.ts            ← 唯一的语言清单 / DANH SÁCH ngôn ngữ DUY NHẤT / the ONLY language list
├── detect.ts            ← 初始语言检测：localStorage → 浏览器 → vi
├── resources.ts         ← 用 import.meta.glob 自动加载所有 locale JSON（无需手动登记）
├── index.ts             ← i18next 初始化
├── LanguageProvider.tsx ← useLanguage() 钩子：当前语言 / 切换 / 清单
├── i18n.test.mjs        ← key 一致性 + 配置测试
└── locales/
    ├── vi/  common.json  nav.json  settings.json  …
    ├── zh/  common.json  nav.json  settings.json  …
    └── en/  common.json  nav.json  settings.json  …
```

`namespace`（命名空间）= 一个 JSON 文件 = 一块功能区域，例如 `nav`（导航）、
`settings`（设置）、`common`（通用按钮/状态）。按页面或功能拆分，保持文件小而聚焦。
每个 namespace 必须先有 `vi`；其它语言可以暂时省略文件，i18next 会自动继承越南语，
这样新增模块时始终有可用的越南语界面，再按模块逐步补齐其它语言。

## 在组件里用翻译 / Dùng bản dịch trong component / Using translations

```tsx
import { useTranslation } from "react-i18next";

function Example() {
  const { t } = useTranslation("nav");            // 选命名空间 / chọn namespace
  return <span>{t("items.home")}</span>;          // nav.json → items.home
}
```

跨命名空间 / xuyên namespace / cross-namespace:

```tsx
const { t } = useTranslation(["nav", "common"]);
t("items.home");              // 默认第一个 ns
t("common:state.comingSoon"); // 显式指定 ns
```

带变量 / có biến / with variables — 在 JSON 里写 `"greeting": "Xin chào {{name}}"`:

```tsx
t("greeting", { name: "Quang" });
```

切换语言 / đổi ngôn ngữ / switch language:

```tsx
import { useLanguage } from "@/i18n/LanguageProvider";
const { language, languages, setLanguage } = useLanguage();
setLanguage("en"); // 自动持久化到 localStorage
```

现成的切换器组件：`<LanguageSelector />`（设置页）与 `<LanguageSelector compact />`（顶栏）。

## 新增一门语言 / Thêm một ngôn ngữ / Adding a language

举例加日语 `ja` / ví dụ thêm tiếng Nhật `ja` / e.g. add Japanese `ja`:

1. `client/src/i18n/config.ts` → 往 `SUPPORTED_LANGUAGES` 加一项：

   ```ts
   { code: "ja", nativeLabel: "日本語", englishLabel: "Japanese" },
   ```

2. 复制 `locales/vi/` 为 `locales/ja/`，翻译每个 JSON 的值（key 不要动）。如果某个 namespace 尚未翻译，
   可以先不创建该文件，运行时会回退到 `vi`。

3. 完成。`resources.ts` 会自动发现新目录，切换器自动多一项。

   跑 `pnpm --filter @ai-novel/client i18n:check` 确认没有漏 key。

> ⚠️ 不要只建目录不放 JSON——至少要有和 `vi/` 一样的命名空间文件集合。

## 新增 / 修改文案 / Thêm hoặc sửa văn bản / Adding or changing copy

1. 先在 `locales/vi/<namespace>.json` 添加 key；其它语言可随后补充，缺失文件或 key 都会回退到 `vi`。
2. 新页面就新建一个命名空间文件（三种语言各一个），`resources.ts` 会自动加载。
3. 跑校验：

   ```bash
   pnpm --filter @ai-novel/client i18n:check   # key 一致性 / tính đồng bộ key / key parity
   pnpm --filter @ai-novel/client test         # 包含 i18n.test.mjs
   ```

## 迁移剩余的硬编码字符串 / Di chuyển các chuỗi còn hardcode / Migrating remaining hardcoded strings

历史代码里还有大量中文直接写在 `.tsx`/`.ts` 里。用扫描脚本分批清理：

```bash
pnpm --filter @ai-novel/client i18n:scan            # 汇总：哪些文件、各多少条
pnpm --filter @ai-novel/client i18n:scan -- --list  # 逐条列出 file:line
pnpm --filter @ai-novel/client i18n:scan -- --json > i18n-todo.json
```

每个文件的迁移套路 / quy trình cho mỗi file / per-file recipe:

1. 选/建一个命名空间（通常按页面，如 `novels`、`comic`）。
2. 把该文件的中文抽到 `locales/zh/<ns>.json`，起语义化的 key。
3. 在 `locales/vi/<ns>.json`、`locales/en/<ns>.json` 补同样的 key + 译文。
4. 组件里 `const { t } = useTranslation("<ns>")`，把字面量换成 `t("key")`。
5. `i18n:check` + `typecheck` + 该文件相关测试。

**扫描脚本会跳过这些**（是数据 / 提示词 / 后端契约，不是 UI，**不要**翻）：
`src/i18n/**`、`**/*.test.*`、`tests/**`、`src/api/**`、任何路径含 `prompt` 的文件。
若发现别的「必须保持原文」的字符串，加进 `client/scripts/i18n-scan.mjs` 的 `EXCLUDE`。

> ⚠️ 部分组件带「设计契约」测试（`*DesignContracts.test.*`、`*.test.mjs`），会断言源码里存在
> 某段中文文案。迁移这类组件时，要把断言改成校验 `locales/zh/<ns>.json`（示例见
> `tests/mobileSiteNavigation.test.js` 的改法）。
>
> Một số component có test "design contract" khẳng định chuỗi tiếng Trung nằm trong mã nguồn.
> Khi migrate, sửa assertion sang kiểm tra `locales/zh/<ns>.json` (xem `tests/mobileSiteNavigation.test.js`).
